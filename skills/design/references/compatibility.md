# Compatibility layer

Original files are fetched unchanged. Our routing and environment rules sit above
them. Upstream README commands do not expand the current task's authorization.

## Taste

The package includes assets, data, references and scripts. Its website layout and
content constraints apply only when that workflow fits the brief. Do not run
`consistency.mjs`, `perf.mjs`, `shoot.mjs`, `check.mjs` or other Chrome/Edge/headless/
CDP browser checks in this workflow. Recreate relevant checks in BrowserOS Neo:
target viewports, empty visuals, overflow, states, fonts/images and reduced motion.
This adaptation does not establish equivalence to the upstream detector.

## Impeccable

Read the relevant playbook and craft floor. Use the original direct-context fallback
when its launcher is unavailable: read the current project documents directly and
state that engine context loading did not run. This bundle installs no engine.

Do not automatically run install/update/hooks/live/Apply or package subagents.
Upstream live Apply may launch a separate CLI with approvals/sandbox disabled;
it is outside this workflow. Static source checks and rendered checks are distinct;
web rendering checks use Neo. Do not report a detector result that did not run.

## Other sources

UI/UX Pro Max uses Python's standard library. Load its skill and focused references,
not every upstream workflow. Guidance does not substitute for product research.

Emil's original metadata is preserved, including explicit-only tasks. Platform and
UI-library installation remains a separate, task-specific choice.

Google DESIGN.md is installed as a specification, not a CLI. If adding its optional
npm validator, verify the published version separately against the selected spec.
Do not assume that the source version exists on npm or supports identical fields.

Awesome Design MD contains references. Check an individual reference's format and
provenance; inclusion does not authorize reuse of another brand or product facts.

Git fetch/archive/ls-remote are source-distribution operations. Website reading and
browser checks use Neo. Never copy credentials, browser profiles or sensitive logs
into project artifacts or a public repository.
