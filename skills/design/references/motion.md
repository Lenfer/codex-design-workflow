# Motion across stages

At concept time define the purpose: explanation, orientation, feedback or a state
change. Consider frequency: everyday actions should not wait for decoration.

In the system specify start/end/intermediate states, triggers, origin, duration
and easing or spring parameters, interruption, repetition, reduced motion and a
static equivalent. Penpot stores states and specifications; a working prototype
can be a separate artifact when necessary.

Resolve `emil` and choose the relevant original using [routing](routing.md). Web and
Expo animation use different skills. Performance work starts from reproduced jank.
Opportunity discovery, choreography and motion removal apply within the requested
scope. Preserve explicit-only behavior of original skills.

In code and real playback check rapid repetition, interruption, feedback latency,
reduced motion, keyboard/pointer interactions and meaningful performance. Motion
must preserve accessible actions and required information. A motion specialist
does not redefine an approved palette or brand.
